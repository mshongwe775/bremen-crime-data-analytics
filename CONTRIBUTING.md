# Contributing

Keep original notebook ownership and contribution history accurate. Use a branch for future contributions and describe the analytical change, source version, affected files and checks in its pull request.

Preserve raw data, permanent report IDs, source manifests, embeddings and the frozen preparation. Keep code simple and paths relative. Never replace uncertain computational labels with invented human decisions or present source-text screening as confirmed victim counts.

Run the relevant notebook from a fresh kernel and `python scripts/check_project.py`. Saved-model mode avoids unnecessary fitting; exact refits require the recorded model environment. Retain Unknown/unassigned cases and reconcile denominators.

Before removing files, retain a recoverable local backup and an affected-file inventory. Do not commit local backups, environments, caches or credentials. A local backup for the current simplification is already available under `_backups`.

Only integrate into the Main Working Station or commit/push when the project coordinator explicitly requests that step. Current cleanup does neither. Follow the supplied course instructions for GitHub access and the instructor invitation at submission time.
